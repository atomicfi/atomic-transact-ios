# Agent Guide

This repository is a release mirror. It holds the public iOS SDK package and its example app, published automatically from `ios-sdk` (under `Public/atomic-transact-ios/`), and the next release can overwrite any change made here.

Don't edit files, commit or open a pull request in this repository. Make the change in `ios-sdk` (under `Public/atomic-transact-ios/`) instead, following that repository's `AGENTS.md`.

If the user isn't part of Atomic, they should open a GitHub issue on this repository for a bug, question or feature request instead of a pull request. For a bug, they should also report it to their Atomic account manager. `CONTRIBUTING.md` lists what to include.
